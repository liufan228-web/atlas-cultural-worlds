# ATLAS 0.3 — Visual Cultural Universe

A Next.js prototype for exploring culture through visual artifacts rather than a conventional node graph.

## New in 0.3
- Image-based cultural universe
- Surprising Connection cue
- Take Me Somewhere interaction
- 3-level semantic zoom control
- Visual Journey Trail
- WHY / SOURCE / EXPLORE panels
- Explicit knowledge status and visual-rights labels
- Local demo visuals only: no scraped copyrighted images

## Rights architecture
The bundled visuals are original procedural demo SVGs created for this prototype. They are not presented as historical documents. Before replacing any demo visual with archival media, verify the object-level reuse rights and preserve creator, institution, source, licence/rights statement, and attribution data.

npm install
npm run dev
